# Datus Azure plugins

| Command | Distribution | Purpose |
|---|---|---|
| `datus aks` | `datus-aks-plugin` | Inspect AKS and authenticate `datus k8s` |
| `datus adls` | `datus-adls-plugin` | Browse Blob/ADLS Gen2 object data and ACLs |

Both depend on `datus-azure-common`, which supports Azure public, China and
government identity/resource-manager endpoints.
